# Визитка Даниила Исаева

Персональный сайт студента СПбГУ. На визитке собраны сведения об учёбе, интересах и навыках, проект Marline на Rust и контакты. Интерфейс доступен на русском и английском. [Открыть визитку](https://danisaev.github.io/)

## Рукопожатие

На странице `/handshake` посетитель может дать Даниилу пять через два экрана. Гость входит через Яндекс ID и отправляет запрос. Когда Даниил принимает его, на обоих экранах почти одновременно сходятся контуры ладоней и появляется карточка с именами участников.

## Технологии

Визитка написана на HTML, CSS и JavaScript с Bootstrap. Flask обрабатывает вход через Яндекс ID и запросы на рукопожатие, SQLite хранит их состояние. Статическую версию публикует GitHub Pages, для Flask-версии в репозитории есть конфигурация Render.
