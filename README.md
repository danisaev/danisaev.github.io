# Личная страница разработчика

Персональный сайт с информацией об авторе, навыках, интересах и проектах. Статическая версия опубликована на [danisaev.github.io](https://danisaev.github.io).

Во Flask-версии есть страница `/handshake`. Гость входит через Яндекс ID и отправляет запрос. Владелец выбирает гостя в очереди, а анимация запускается на обоих экранах по времени сервера.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app app run
```

Визитка открывается на `http://127.0.0.1:5000/`, а рукопожатие — на `http://127.0.0.1:5000/handshake`. Для проверки входа зарегистрируйте `http://127.0.0.1:5000/handshake/callback` в Яндекс ID и перед запуском задайте `YANDEX_REDIRECT_URI` с этим адресом, `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET` и `OWNER_YANDEX_ID` в окружении. Для сохранения сессий при перезапуске задайте постоянный случайный `SECRET_KEY`.

Серверные тесты запускаются командой `python -m unittest discover -s tests`.

## Публичный запуск на Render

1. Создайте Blueprint из этого репозитория. В `render.yaml` уже заданы команда запуска Gunicorn, бесплатный план и генерация ключа сессии. После первого запуска у сервиса появится HTTPS-адрес.
2. Создайте [приложение Яндекс ID](https://yandex.ru/dev/id/doc/ru/register-client) для веб-сервиса. Включите право `login:info` и зарегистрируйте адрес возврата `https://<адрес-сервиса>/handshake/callback`. В окружении Render задайте `YANDEX_CLIENT_ID` и `YANDEX_CLIENT_SECRET`. Адрес возврата Flask вычислит из `RENDER_EXTERNAL_URL`. Для собственного домена укажите полный адрес возврата через `YANDEX_REDIRECT_URI`.
3. Войдите на `/handshake` под аккаунтом владельца. Пока `OWNER_YANDEX_ID` не задан, страница после входа показывает ваш ID под пунктом «Твой ID аккаунта Яндекса». Сохраните его как `OWNER_YANDEX_ID` в окружении Render и дождитесь перезапуска.
4. В настройках репозитория GitHub создайте переменную Actions `HANDSHAKE_URL` с полным адресом `https://<адрес-сервиса>/handshake` и запустите workflow **Deploy GitHub Pages**. Ссылка появится и на статической визитке.

Перед показом откройте публичную страницу на двух устройствах под разными аккаунтами. С гостевого устройства нажмите «Дать пять», затем подтвердите запрос со страницы владельца. На бесплатном Render сервер засыпает при простое, а SQLite сбрасывается при перезапуске или новом развёртывании.
